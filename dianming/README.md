# 课堂点名系统

这是一个简单实用的课堂点名系统，可以帮助教师快速完成课堂点名和考勤记录工作。

## 功能特点

- **随机点名**：随机选择学生进行点名，增加课堂互动性
- **顺序点名**：按学生名单顺序进行点名
- **考勤记录**：记录学生出勤、迟到、缺席情况
- **数据导入导出**：支持CSV格式的学生名单导入和考勤记录导出
- **数据统计**：实时统计出勤、迟到、缺席人数
- **本地存储**：自动保存点名数据，下次打开不丢失

## 使用方法

1. 打开`index.html`文件即可使用系统
2. 点击"随机点名"按钮进行随机点名
3. 点击"开始点名"按钮进行顺序点名
4. 为被点名学生选择状态：出勤、迟到或缺席
5. 点击"重置点名"可清空当前点名记录
6. 使用"导入学生名单"功能可导入CSV格式的学生名单
7. 使用"导出考勤记录"功能可导出当前考勤记录为CSV文件

## 键盘快捷键

- `R` 键：随机点名
- `S` 键：开始顺序点名
- `1` 或 `P` 键：标记当前学生为"出勤"
- `2` 或 `L` 键：标记当前学生为"迟到"
- `3` 或 `A` 键：标记当前学生为"缺席"

## 文件说明

- `index.html`：应用主页面
- `styles.css`：样式表文件
- `script.js`：JavaScript脚本文件
- `学生名单示例.csv`：示例学生名单，可用于测试导入功能

## 注意事项

- 本应用使用浏览器本地存储保存数据，清除浏览器缓存可能导致数据丢失
- 导入的CSV文件格式必须为：第一行为标题行（学号,姓名），之后每行为一名学生的信息
- 为获得最佳体验，建议使用Chrome、Firefox或Edge等现代浏览器
