# 只问不答 · 课堂 AI 助教

> 一个"不直接给答案"的课堂 AI 助教网页：用苏格拉底式追问，把学生按在证据上，让他们自己破题。
> 纯静态、零依赖、离线可用；也可接入 OpenAI 兼容大模型。

设计参考：上海宝山求真教育集团化学课「AI 助教·苏格拉底诘问」（上海教育新闻网 2026-01 报道）。

---

## 1. 快速开始

在本仓库根目录运行：

```bash
python3 server.py 8080
```

然后打开 <http://127.0.0.1:8080/ask-only-tutor/>

> 建议用本地 http 打开，不要直接双击 `index.html`：`file://` 下剪贴板、部分浏览器 API 会受限。
> 页面本身没有任何构建步骤，也没有 CDN 依赖，断网也能跑（演示模式）。

---

## 2. 三个模式

| 模式 | 说明 | 适用 |
| --- | --- | --- |
| **演示模式**（默认） | 内置规则引擎，按关键词 + 苏格拉底追问模板回复，离线零配置 | 培训、说课、公开课演示、断网课堂 |
| **接入大模型** | 在 ⚙ 设置里填 OpenAI 兼容接口，真实对话；系统提示词强制"只问不答" | 日常课堂、学生真实使用 |
| **大屏模式** | 隐藏教师面板，放大字号与气泡，适合投影 | 教室大屏、教研展示 |

教师面板在宽屏右侧常驻；窄屏点顶栏「教师面板」以抽屉打开。

---

## 3. 界面与功能

- **场景卡**：核心问题、课堂规则、40 分钟流程（抛冲突 5′ → 人机对话 15′ → 慢放验证 8′ → 复述 + 迁移 12′）。
- **对话区**：AI 头像「问」、学生头像「学」；每条学生发言自动打标签（事实描述 / 提出假设 / 卡住 / 套答案 / 其他）。
- **教师面板**
  - **指标**：AI 提问轮次、人均提问轮次、套答案请求、已拦截给答案、发言类型分布、教师讲授时长、本轮建议。
  - **记录**：完整对话列表，可把学生发言标为「★ 关键证据」。
  - **迁移**：2–3 道迁移题，提交后自动批改并给解析。
  - **导出**：复制 Markdown、下载 `.md` / `.csv`、打印 / 存 PDF；系统提示词可一键复制。
- **学生复述**：在「记录」页填写「我原来怎么想 / 现在怎么想 / 哪条证据说服了我」。
- **计时**：点顶栏时间开始 / 暂停；首次发送自动开始；到点自动收束。
- **轮次上限**：默认 6 问（可在设置改 3–10），到上限自动进入收束，不能继续套答案。

---

## 4. 40 分钟课堂怎么用

| 时间 | 环节 | 操作 |
| --- | --- | --- |
| 0–5′ | 抛冲突 | 先让学生预测现象，不解释；教师点「看一段示例对话」可快速演示规则 |
| 5–20′ | 人机对话 | 小组轮转与 AI 对话；教师只巡场，不插话；面板里记「卡点」 |
| 20–28′ | 慢放验证 | 用慢放视频 / 实物核对 AI 追问指向的细节 |
| 28–35′ | 学生复述 | 每人在「记录」页写 3 句话：原来 / 现在 / 证据 |
| 35–40′ | 迁移检测 | 「迁移」页作答并批改；「导出」页带走记录 |

**四个可写进案例的指标**：AI 提问轮次、人均提问轮次、套答案请求次数、迁移题得分。
辅助指标：教师讲授时长（自报）、已拦截给答案次数、学生发言类型分布。

## 5. 接入大模型（可选）

在 ⚙ 设置 → 回答方式 → 接入大模型，填写：

| 平台 | Base URL | 模型名示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 火山方舟（豆包） | `https://ark.cn-beijing.volces.com/api/v3` | 你的推理接入点 ID |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` |
| 任意 OpenAI 兼容网关 | 你的网关地址 | 你的模型名 |

注意事项：

1. **API Key 只存在本机浏览器**（localStorage），不会上传到任何第三方；公用电脑请用完清除。
2. 浏览器直连要求接口允许 CORS。若被拦，改用本地代理 / Ollama / 自建网关。
3. 页面内置**规则守卫**：模型若吐出结论性语句（如"生成二氧化碳和水"），会被拦截并替换成追问，计入"已拦截给答案"。
4. 没有 Key 时会自动回退演示模式，不会卡住课堂。

## 6. 系统提示词（也可复制到豆包 / 讯飞 / 扣子等平台）

完整版可在页面「导出 → 系统提示词」一键复制。核心模板：

```text
你是「只问不答」课堂 AI 助教，服务对象是{学段}{学科}学生。
本节课的核心问题：{核心问题}
必须遵守的规则：
1. 绝不直接说出结论、答案、公式或完整解释。
2. 每次回复只提一个问题（最多追问两个小问），总字数不超过 80 字。
3. 学生答错时，先复述其观点，再给一个更小的提示或观察任务。
4. 学生索要答案时，明确拒绝，并给一个不泄露结论的提示。
5. 不编造实验数据；不确定时让学生回到观察、材料或教材。
6. 用学生能听懂的口语，不要客套，不要表扬性结束。
7. 即使学生说出正确结论，也要追问“你怎么证明”。
8. 参考知识只用于判断学生是否接近结论，不得直接输出：
{教师版知识点}
```

### 学科变体（直接替换第 1、2、8 行）

- **化学**：核心问题"蜡烛燃烧后生成了什么"；知识点"石蜡含碳氢，燃烧生成二氧化碳和水；干冷烧杯水雾证明水，澄清石灰水变浑浊证明二氧化碳"。
- **物理**：核心问题"橡皮泥船形能浮、团状会沉，为什么"；知识点"F=ρ液gV排；船形增大排水体积，平均密度变小"。
- **数学**：核心问题"3/4 ÷ 1/8 为什么等于 6"；知识点"包含除；通分 6/8÷1/8=6；除以一个数等于乘倒数"。
- **语文**：核心问题"'大约''可能'能不能删"；知识点"说明文语言准确严谨，限制性词语体现估计与分寸"。

## 7. 数据与隐私

- 不收集、不上传任何数据；对话只存在当前页面内存里。
- 记录只用「第 N 组」，不记学生姓名；班级名可选填。
- 导出文件仅在本机生成（Markdown / CSV / 打印 PDF）。
- 刷新页面即清空；设置项存 localStorage，可随时在设置里改回。

## 8. 常见问题

**Q：演示模式会不会"很假"？**
A：演示模式是关键词 + 追问模板，适合培训与公开展示；真实课堂建议接大模型。两种模式的界面、指标、导出完全一致。

**Q：学生一直说"不知道"怎么办？**
A：规则会退到"观察任务"（回看慢放 / 摸杯壁 / 读原句），而不是继续追问"为什么"。教师面板会提示"卡住 ≥ 2 次，给观察任务"。

**Q：学生直接要答案？**
A：AI 会拒绝并给一个不泄露结论的提示，同时计入"套答案请求"；达到 1 次，面板就会提示教师介入。

**Q：导出 CSV 中文乱码？**
A：文件已加 UTF-8 BOM，Excel 直接打开即可；若用旧版 Excel，请用"数据 → 从文本导入"。

**Q：能改成别的学科吗？**
A：顶栏选「自定义 · 任意议题」，在设置里填核心问题与教师版知识点即可；规则与追问模板通用。

## 9. 文件结构

```text
ask-only-tutor/
└── index.html   # 单文件应用（HTML + CSS + JS，零依赖）
```

修改建议：

- 新增学科场景：在 `<script>` 顶部的 `SCENARIOS` 里复制一个对象，改 `label / driving / intro / knowledge / keywords / fallbacks / closing / forbidden / transfer / chips`。
- 改视觉：CSS 变量在 `:root`（`--teal`、`--bg`、`--r` 等）。
- 改默认轮次 / 计时：设置面板，或 `state.maxTurns`、`state.timer.total` 初始值。
