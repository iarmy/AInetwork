# 空中画函数 · 手势演示（网页版）

报告《人工智能赋能数学教育教学的实践路径》的开场暖场环节。

**开场**：左手控制【AI】圆、右手控制【数学】圆，推到中间相遇后两圆消失 → 隔空画函数曲线 → 画几何图形看 AI 露怯 → 最后**双手对碰揭题**。

> 识别引擎 + 手势模型已全部本地化（`lib/`、`model/`），**无需联网即可运行**。

## 一、怎么跑

**必须用本地静态服务器打开**（ES 模块 + 摄像头权限都不支持直接双击 `file://`）：

```bash
cd /Users/fjchen/Documents/Deepseek/gesture-demo
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

点「允许摄像头并开始」，几秒内即可就绪（模型在本地，不联网）。

> 换端口也行，改 `8000` 为任意端口号，访问地址同步改。

## 二、手势与流程

| 阶段 | 手势 | 屏幕上发生什么 |
|---|---|---|
| 开场 · AI 遇见数学 | **双手**：左手控【AI】圆、右手控【数学】圆，推到中间 | 两圆跟随手掌，到中间相遇后**缩小消失** |
| ① 亮出双手 | **五指张开** → 开始 | 显示手部骨骼点，AI"看着"你的手 |
| ② 空中画曲线 | **只伸食指** 画一条抛物线；**握拳**＝画完 | 指尖轨迹实时描成曲线 |
| ③ AI 拟合 | 自动；看完后**松开**拳头、再**五指张开**＝继续 | 拟合出解析式 + R² + 一句讲解 |
| ④ 画几何图形 | **只伸食指** 画三角形/圆；**握拳**＝画完 | 轨迹记录 |
| ⑤ AI 露怯 | 自动 | AI 强行拟合并报"置信度 91%"——即使它不满足函数定义 |
| ⑥ 揭题 | **双手对碰** | 全屏**定格**报告题目 + 主讲人（手势不再返回） |

> **重要**：每做完一个确认手势，先**把手势松开**，再做下一个动作。系统要求「松开才算数」，这是为了防止确认时还握着的拳头被误当成下一次触发而跳过第 ③/④ 步。

## 三、防翻车备用（务必彩排）

- **屏幕右下角**：`下一步 ›` / `重来 ↺` 按钮，鼠标点击即可推进/重开。
- **键盘**：`空格` 或 `→`＝下一步；`R`＝重来。
- **结尾定格**：揭题后画面固定在报告题目页，任何手势都不会退出；如需再演示一遍，按 `R` 键或刷新页面重来。
- 手势触发已做"稳定帧"防抖（需稳定约 0.16 秒），且每次进入新阶段有 0.8 秒冷却、并要求"先松开上一手势"，避免上一动作误触发/跳步。

改题目、两个圆的文字/颜色/起始位置都在这里。

## 五、文件结构

```
gesture-demo/

├── lib/
```

这些文件已随项目本地化，无需外网。升级识别引擎时替换 `lib/` 下对应文件（引擎与 wasm 版本需一致）。

## 六、现场彩排要点

1. 固定机位、距离、灯光（顶光/逆光会让骨骼点跳，尽量正面均匀光）。
2. 开场双手两圆：注意**两只手都别出框**，推到中间时两圆距中心各在约 15% 画宽内即触发消失。
3. 后续只练两个动作：**抛物线**、**三角形或圆**，别临时加动作。
4. 揭题用**双手对碰**：第五步画面里会有一条两只手之间的虚线，变绿并显示「✓ 对碰」即触发（掌心距约在 18% 画宽内）。
5. 讲解文字目前是占位文案，若要接 DeepSeek 实时生成，替换 `showResultPanel` 里的提示文案为接口调用即可（建议仍预缓存一份兜底）。
