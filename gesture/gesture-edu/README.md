# AI 手势课堂反馈（数学）

课堂**即时反馈**工具：老师投出选择题，学生对着摄像头用手指比出选项号，
屏幕**实时统计全班答案分布**；老师可随时定格本轮结果、公布答案看正确率。

> 只数【食指 / 中指 / 无名指 / 小指】四根手指 —— 判据是"指尖到手腕的距离
> 大于第二关节到手腕的距离"，这个判据对光照和手掌朝向都比较宽容。
> 竖起大拇指的判定在真实教室光照下容易抖，所以答项定为 **4 个（A~D）**。

## 一、怎么跑

**必须用本地静态服务器打开**（ES 模块 + WebAssembly + 摄像头权限都不支持 `file://`）：

```bash
cd /Users/fjchen/Documents/AInetwork

# 浏览器打开 http://127.0.0.1:8080/gesture/gesture-edu/
```

点「允许摄像头并开始」，几秒内即可就绪。
识别引擎与模型都放在本地 `lib/`、`model/`，**不联网也能跑**。

### 没有摄像头 / 课前试讲：彩排模式

在地址后面加 `?demo=1`：

```
http://127.0.0.1:8080/gesture/gesture-edu/index.html?demo=1
```

不开摄像头、不加载模型，直接用脚本生成的模拟手势跑完整套界面，
用来预览效果或对着投影试讲。界面上会常驻「彩排模式 · 模拟数据」角标，
不会和真实识别混淆。

## 二、课堂怎么用

1. 把投影切到本页，让学生看到题目和 A~D 四个选项。
2. 喊口令：「请用手指表示你的答案 —— 1 根手指选 A，2 根选 B，3 根选 C，4 根选 D。」
3. 学生**手掌正对镜头、手指张开**举向摄像头（画面里最多同时认 4 只手）。
4. 屏幕右侧柱状图实时跳动，选项行同时显示票数。
5. 点 **「定格统计」** 锁定本轮结果（学生可以放下手了）。
6. 点 **「公布答案」** —— 正确选项变绿、错选变暗，并显示正确率。

### 按钮与快捷键

| 操作 | 按钮 | 快捷键 |
|---|---|---|
| 定格 / 继续实时 | 定格统计 | `空格` |
| 公布答案 | 公布答案 | `Enter` |
| 上一题 / 下一题 | 上一题 / 下一题 | `←` `→` |
| 重置本轮 | 重置 | `R` |

换题会自动重置本轮统计，上一题的"正确/错误"高亮也会一并清掉。

## 三、题库

内置 **8 道小学数学选择题**（每题 4 个选项），在 `index.html` 顶部 `QUESTIONS` 里改：

```js
const QUESTIONS = [
  { q: '3 + 4 = ?',   options: ['5', '6', '7', '8'], answer: 2 },   // answer=2 → C
  ...
];
```

- `q` 题干，支持任意文字
- `options` 四个选项，按 A/B/C/D 顺序
- `answer` 正确选项下标：`0=A, 1=B, 2=C, 3=D`

想换成别的学科或更多题，直接往数组里加即可，页面上会自动显示总题数。

## 四、可调参数

`index.html` 顶部 `CONFIG`：

```js
MAX_HANDS: 4,          // 同时识别的手数
STABLE_FRAMES: 5,      // 同一只手连续多少帧结果一致才计入（防抖）
MISS_FRAMES: 8,        // 连续多少帧没看到就认为这只手放下了
FINGER_RATIO: 1.08,    // 指尖离手腕 > 第二关节离手腕 × 该系数 → 判定伸直
```

**识别不灵敏时先调这两个**：

- 学生手指没伸直就被算成"握拳"→ 把 `FINGER_RATIO` 调小（如 `1.02`）
- 画面里手一晃票数就跳 → 把 `STABLE_FRAMES` 调大（如 `8`）

数手指用的是 MediaPipe 的 **worldLandmarks（真实三维米制坐标）**，不是画面上的二维坐标 ——
手掌朝向镜头、手指被透视压缩时，二维投影会把伸直的指头算短，三维距离不受影响。

## 五、排查：一直显示「识别到 0 只手」

界面已经把这些情况显式提示出来，不用猜：

| 界面提示 | 含义与处理 |
|---|---|
| `等待投票` | 正常，还没人比手势 |
| `一直没有识别到手：请把手掌正对镜头…（已运行 N 秒）` | 跑满约 10 秒仍一只都没认出来。多半是手太小 / 光线太暗 / 逆光，也可能是摄像头被别的软件占用 |
| `识别出错：<原因>` | 识别引擎真的报错了，页面会给出原始错误信息，刷新页面重试 |

> **开发者注意**：本地用的是 **Tasks 版** `HandLandmarker`，结果字段是
> `landmarks` / `worldLandmarks` / `handednesses`。
> 旧版 `Hands` 方案才叫 `multiHandLandmarks` —— 读错字段不会报错，
> 只会永远"识别到 0 只手"（骨架和票数全都出不来）。代码里两个都读了一遍以防万一。

## 六、现场要点

1. **光线**：人物正面柔和照明，避免强逆光 / 顶光，否则手指关键点会跳。
2. **距离**：学生手掌占画面 1/4 以上，识别最稳；太远会认不出手指数。
3. **手指数要张开**：四指并拢容易把相邻手指误判成"弯曲"。
4. **一屏最多 4 只手**：这是电脑摄像头能稳定同时跟踪的上限。
   全班投票建议分组轮流比，或者用它做**抽样快速反馈**（谁想发言谁比手）。
5. **统计的是"当前画面里的手"**，不是全体名单 —— 所以「定格」这一步很重要：
   定格前请让学生保持手势，定格后统计就锁住了。

## 七、文件结构

```
gesture-edu/
├── index.html               # 演示本体（单文件逻辑）
├── lib/
│   ├── vision_bundle.js     # 手势识别引擎（ES 模块，本地加载）
│   └── wasm/                # 引擎的 wasm 运行时
└── model/
    └── hand_landmarker.task # 手部关键点模型（约 7.8MB）
```

`lib/` 与 `model/` 是从 `../gesture-demo/` 复制过来的**同一份引擎**。
升级识别引擎时两边都要替换（引擎与 wasm 版本必须一致）。
